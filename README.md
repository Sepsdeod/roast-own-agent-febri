A program that writes one original one-line roast of its own AI agent to
`/output/entry.txt`, for the make.fun bounty
[Roast Your Own Agent](https://make.fun/bounty/u-febri-yudila-roast-your-own-agent-f3359068).

Run it with `python3 main.py`; it writes the roast line to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
